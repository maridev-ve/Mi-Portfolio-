# Portfolio de Mariela

Portfolio personal como Desarrolladora Front-End. Aquí muestro quién soy, los proyectos que he hecho durante mi formación y cómo contactarme.

🔗 **Ver la web:** https://github.com/maridev-ve/Mi-Portfolio-.git

## Tecnologías

- HTML5
- CSS3 (Flexbox, media queries, diseño mobile first)
- JavaScript (menú hamburguesa)

## Proyectos incluidos

| Proyecto | Descripción |
|---|---|
| Validador de Emails | Validación de formularios en tiempo real |
| Buscador de Autos | Búsqueda con filtros múltiples |
| Gestor de Tweets | CRUD con LocalStorage |
| Carrito de Compras | Carrito con persistencia y cálculo de totales |
| Calculadora de Seguros | Cotizador con prototipos y POO |
| Gestor de Gastos Semanales | Control de presupuesto con clases ES6 |

Todos están en la carpeta `-proyectos-/` y se pueden abrir desde el botón "Ver demo" de cada card.
